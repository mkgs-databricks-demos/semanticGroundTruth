## Key decisions

| Decision | Rationale |
|----------|-----------|
| MCP service belongs in app bundle | Depends on app's `/mcp` endpoint; can't deploy until app exists |
| `engine: direct` added to app | Required for `mcp_service` resource type |
| `schema_name` var (not `schema`) | Distinguishes from infra's `schema` var; holds full UC name including dev prefix |
| Agent skills volume deferred | Optional resource; local `server/agents/skills/` works without UC volume |
| `freshness_resurfacing` is correct job | Resurfaces stale confidence scores — exactly what review UI would trigger |
| Serving endpoint stays hardcoded | Workspace-level concern, not bundle-managed |
