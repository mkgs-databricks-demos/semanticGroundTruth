## Design Decisions

* **Stateless per-request**: new `McpServer` + `StreamableHTTPServerTransport({ sessionIdGenerator: undefined })` per `POST /mcp`. No sticky sessions. Scales horizontally.
* **User context via closure**: `getUser(res)` extracts `UserContext` from middleware-set `res.locals.user`; all tools close over this — no separate auth inside tools.
* **`review_submit_vote` asset_id default**: Made `asset_id` optional in the MCP tool schema. Falls back to `McpSessionStore.get(userId).currentAssetId`. Throws `BAD_REQUEST` if neither available.
* **Metric view OBO guard**: Private `requireObo(user)` throws a descriptive `FORBIDDEN` error when `user.accessToken` is absent (M2M gateway without token forwarding). Recorded as assumption.
* **Resource registration**: `ui://ground-truth/review-card` registered as an MCP resource with a placeholder card. `review_get_next` returns the real card HTML in `_meta` alongside the markdown text content.
* **Error handling**: Every tool handler wrapped in try/catch → `toToolError`. No stack traces or tokens in error messages.
* **Test file**: `markdown.test.ts` covers rendering + escaping for all 4 markdown functions plus `renderCardHtml` (brand colours, XSS escaping, content). Written per plan; cannot run (no Node toolchain).

## Assumptions

* `@modelcontextprotocol/sdk` ^1.23 `McpServer.tool()` accepts raw zod shapes (from `McpToolShapes`) as `inputSchema`. If the installed SDK’s zod peer is v3 and conflicts with zod v4, the controller resolves it at deploy time.
* `AssetRegistry` exposes `addSynonym(assetId, synonym, userId)`, `removeSynonym(assetId, synonym)`, `approveSynonym(assetId, synonym, userId)`, `rejectSynonym(assetId, synonym, userId)` and `addExample(assetId, questionText, userId)`, `approveExample(assetId, questionId, userId)`, `rejectExample(assetId, questionId, userId)` per session 09’s route dispatch (switch on `action`). Exact signatures are based on the route handlers.
* Metric view tools return a tool error (not throw) when OBO token is absent. M2M gateway calls will see this until token forwarding is configured.
* `McpServer.resource()` accepts `(name, uri, metadata, handler)` for registering resources. Best-effort; the markdown text content is always the primary response.
