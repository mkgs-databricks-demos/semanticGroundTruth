# Databricks brand assets

These files are the official assets referenced by Section 4 of
`docs/design/ui/figma_make_brief.md`. They are stored locally so the reference
export does not fetch the Brandfolder CDN at runtime.

The two Databricks symbols were copied from
`ground-truth-app/client/public/brand/`. The remaining SVGs were downloaded
using the exact filenames and attachment IDs in Section 4.

The brief names six additional catalog assets without publishing attachment
IDs. They are not included yet:

- `copyIcon.svg`
- `fileCodeIcon.svg`
- `arrowUpIcon.svg`
- `arrowDownIcon.svg`
- `SendIcon.svg`
- `FolderBranchIcon.svg`
